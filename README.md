## ![](https://api.iconify.design/lucide/globe.svg?color=8b5cf6&height=20) Live Demo

Ini repo dokumentasi. Produknya **NexBot** — bisa langsung dicoba di browser.

1. **[Daftar](https://beta.toolwiz.id/signup)** di [beta.toolwiz.id](https://beta.toolwiz.id) — lewat Email, Google, GitHub, atau Telegram.
2. **Verifikasi** akun dengan kode yang dikirim ke WhatsApp.
3. **[Login](https://beta.toolwiz.id/signin)**, lalu pindai QR dari menu **Connect / Scan QR**.

Selesai — bot online. Pilih paket **Basic Rp 5.000 / 30 hari** untuk mengaktifkan semua command.

> Tidak perlu install apa pun, tidak perlu VPS, tidak perlu Node.js.
> Nomor tetap milik Anda, dan bisa di-*logout* kapan saja.

<details>
<summary><b>Detail: cara daftar, login, dan verifikasi</b></summary>

**Metode pendaftaran dan login** — empat cara, tersedia langsung di halaman signup dan signin:

| Metode | Keterangan |
|---|---|
| Email | Daftar / masuk dengan email dan kata sandi |
| Google | Masuk lewat akun Google |
| GitHub | Masuk lewat akun GitHub |
| Telegram | Masuk lewat akun Telegram |

**Alur verifikasi**

1. Setelah daftar, NexBot mengirim kode verifikasi ke nomor WhatsApp Anda.
2. Buka `/verify` dan masukkan kodenya.
3. Akun ditandai terverifikasi dan baru bisa membuka dashboard.

Kode dikirim ke **WhatsApp**, bukan email — pastikan nomor Anda aktif.

**Lupa kredensial** — tiga halaman saling terhubung dari halaman login, jadi tidak perlu menghubungi admin: `/forgot-username`, `/forgot-password`, dan `/reset-password`.

</details>

## ![](https://api.iconify.design/lucide/message-circle-question.svg?color=8b5cf6&height=20) FAQ

<details><summary>Perlu kemampuan coding?</summary>

Tidak. Semua dikelola lewat dashboard: scan QR, pilih command, atur template, atur role.

</details>

<details><summary>Harus punya VPS sendiri?</summary>

Tidak. Semua berjalan di server NexBot. HP hanya dipakai sekali untuk scan QR.

</details>

<details><summary>Berapa lama bot tetap aktif?</summary>

Selama plan aktif. Tiap paket berlaku 30 hari dan bisa diperpanjang kapan saja.

</details>

<details><summary>Kalau di-update, harus upload ulang?</summary>

Tidak. Pembaruan dikirim ke server dan berlaku untuk seluruh user.

</details>

<details><summary>Nomor WhatsApp saya aman?</summary>

Nomor tetap milik Anda dan bisa di-*logout* kapan saja. Perlu diketahui bahwa otomasi tetap berada pada kebijakan layanan WhatsApp — gunakan sesuai ketentuan yang berlaku.

</details>

<details><summary>Bisa dipakai untuk dijual lagi?</summary>

Bisa. NexBot dirancang untuk dipakai sebagai produk atau jasa berbayar.

</details>

<details><summary>Ada command yang error?</summary>

Laporkan lewat tiket bantuan. Perbaikannya segera dikirim ke semua user lewat update otomatis.

</details>
